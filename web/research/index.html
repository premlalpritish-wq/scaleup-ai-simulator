What the existing protocol establishes

The pecan paper (PMC11430883, Foods 2024) extracts total RNA from Carya illinoinensis embryos with a TRIzol kit, treats with DNase I and checks quality by gel and NanoDrop before small-RNA and transcriptome sequencing. It names the kit and says the manufacturer's protocol was followed.

It does not print the lysis volumes, incubation times, centrifugation speeds, elution volume, yield or RIN. Those stay unknown here.

Where the exact parameters come from

Two other open-access papers give exact modified-CTAB and TRIzol parameters: Norway spruce (Picea abies) and pigeonpea (Cajanus cajan). They are different species, so the workflow records them as analogue hypotheses, never as pecan measurements.

Two method reviews cover secondary-metabolite-rich and difficult plant species.

            Feedback

            Privacy notice

            • Your problem, extraction method, details and observations are sent to this deployment's Python service when you press Run analysis. That is what runs the workflow. They are not sent to any third-party service, and this application has no API key of any kind.
            • Analyses are held in the service's memory and temporary storage for a bounded number of recent runs, and disappear when the service restarts. Export anything you need to keep.
            • Feedback is stored only on this server, and only if the operator configured a feedback directory. The response tells you whether it was stored.
            • No analytics, tracking pixels or third-party scripts are loaded by this page.
            How this page is produced

            The page is static HTML/CSS/JavaScript. It reads the pecan case from GET /api/research/case, which serves the shipped artifacts in composition/workflow_runs/pecan/ after re-verifying every quote at its recorded character offsets. Run analysis calls POST /api/research/analysis, which writes your problem to a temporary file and runs composition.workflow.execute.run_workflow — the same entry point the CLI and the desktop scene use. If this page is served by a static host with no Python service, the API calls fail and this page says so instead of showing sample results.
